## 🚀 Install (one command)

```bash
curl -fsSL https://raw.githubusercontent.com/iMCSxOfficial/imcsx-toolkit/main/web-install.sh | bash
```

An **iMCSx Toolkit** shortcut appears on your desktop. Launch it and you're set.
