## 🚀 Installation (une commande)

```bash
curl -fsSL https://raw.githubusercontent.com/iMCSxOfficial/imcsx-toolkit/main/web-install.sh | bash
```

Un raccourci **iMCSx Toolkit** apparaît sur ton bureau. Lance-le et c'est parti.

> Linux (Kali/Debian/Ubuntu…). Nécessite `curl`.

## 🧰 Modules

| Module | Rôle | Édition |
|--------|------|:------:|
| Scan de ports | Ports ouverts, services, bannières | FREE |
| Découverte d'hôtes | Hôtes actifs (IP ou réseau) | FREE |
| Reconnaissance DNS | A, MX, NS, TXT, SOA, PTR | FREE |
| Sous-domaines | Énumération DNS | FREE |
| Dir scan | Fichiers/répertoires web | FREE |

| Injection de commandes | CMDi | **PRO** |
| LFI / traversée | Inclusion de fichier | **PRO** |
| Bruteforce | Robustesse d'authentification | **PRO** |
